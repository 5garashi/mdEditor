今回のアップデート（1.0.20）

PDFとWordをMarkdownとして開けます。AIチャットの回答も、書き方の癖を直して表示。プレビューどおりのPDFに、ワンクリックで保存できます。

書きながら横で仕上がりを確認。Mermaid・Graphviz・数式・3Dモデル・地図をオフラインで表示。書き間違いには波線、表は Ctrl+Shift+W で整えます。

Windows用・無料。PDFの取り込みはできる範囲での変換で、段組みやスキャンしたPDFは元に戻りません。AIチャットの回答は、できる範囲で再現します。収録はソースビルド1.0.20です。 開発と動画の制作に、AI（Claude・Codex）の支援を受けています。BGMはCodexで作曲・音源生成したものです。

図・3D・地図・動画

Mermaid・Graphviz・数式から、回転できるSTL、GeoJSON、文書内動画まで。

書きながら、仕上がりを見る

連動スクロール、別窓プレビュー、ウィンドウ全体で読む表示。

取り込み、必要な形式で渡す

Word・HTML・メール・CSVなどを開き、PDF・Word・HTML・PNGなどへ保存。

主な20機能

  1. PDF や Word を Markdown として開ける。PC の中だけで変換
  2. PDF から見出し・箇条書き・表・コード・画像を取り出す
  3. ワンクリックで PDF に保存。プレビューと同じ見た目のまま
  4. Word・HTML・PNG・CSV・JSON・テキスト・ZIP にも保存
  5. 書きながら横で仕上がりを確認。スクロールも連動
  6. AI のチャットの Markdown も、できる範囲で再現
  7. プレビューを 2 台目のディスプレイに。編集中の行を表示
  8. 書くそばから色分けし、書き間違いに波線を引く
  9. 太字・斜体・リスト・表・見出しの番号をキー 1 つで
  10. Mermaid・Graphviz の図と数式をオフラインで表示
  11. 3D モデル（STL）と地図（GeoJSON）をオフラインで表示
  12. 約 40 の言語のコードを色分け。見出しから目次も作る
  13. GitHub と同じ注意書き・フロントマター・折りたたみ
  14. HTML・メール・CSV・JSON・Jupyter Notebook・画像も開ける
  15. 画像はドロップや貼り付けで、そのまま文書に
  16. コピーしてキーを押すと、新しい文書として開く
  17. 安全な保存と、異常終了からの自動復元
  18. Shift_JIS・EUC-JP・UTF-8 のファイルを正しく開ける
  19. 広告なし、計測なし、アカウント不要。ネット上の内容は許可したときだけ
  20. キーボード操作・画面読み上げ・文書の読み上げ・ダークモード

文書の形式や読み込み内容によって、引き継がれる情報は異なります。Wordの色・配置や、Notebookの実行結果は再現しません。

画像を入れ、サイズと中央揃えを調整

画像はドロップや貼り付けで入れ、50％幅・中央揃えなどに調整できます（画面は1.0.15）。文書と使った画像はZIPでまとめて渡せます。

外部画像のない、短いサンプルです。PCに保存して使えます。

  1. 保存する下からMarkdown文書を保存。元の文書を残したい場合はコピーを使います。
  2. 開いて、変えるmdEditorの「開く」で選択。文書内の「試してみる」に沿って編集します。
  3. PDFに残す「保存」で文書を保存し、「名前を付けて保存」の種類でPDFを選びます。

文書は、PCの中で。

文書の編集、図・数式の描画、PDF保存はPC内で処理します。mdEditor自体は文書や個人情報を収集・送信しません。

ネット上の画像・動画・地図は、許可した場合に読み込みます。「URLを開く」は指定したhttpsページを取得します。取得先にはIPアドレス等が伝わります。WebView2の更新・診断はMicrosoftの設定に従います。
