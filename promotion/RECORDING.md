# 実機での40秒操作録画台本

この環境ではWindows版を起動できないため、同梱MP4は字幕付き機能紹介です。実演動画への差替えは下記で行ってください。個人情報のないサンプルを使います。

| 秒 | 実機操作 | 字幕 |
| --- | --- | --- |
| 0–5 | mdEditorの初期画面 | Markdownを、伝わる文書に。 |
| 5–12 | quickstart-engineering-note.mdを開く | 図・数式・表を、その場で確認。 |
| 12–20 | 見出しと本文を変更 | 書くと、プレビューも変わる。 |
| 20–27 | プレビューを別ウィンドウに出す | 書く画面と見る画面を分ける。 |
| 27–35 | Ctrl+Shift+Pで保存しPDFを開く | 図と数式ごと、PDFへ。 |
| 35–40 | Store URLと事務所名の終了画面 | mdEditor / 5garashi.com設計事務所 |

英語字幕: Turn Markdown into a document worth sharing. / Preview diagrams, equations and tables. / Edit and see the result. / Separate your writing and preview. / Save the result as PDF.

認定完了後、対象版がStoreから導入できることを確認して撮影・公開します。Windowsの画面録画で1280×720以上、通知を無効化し、BGMなしでも伝わる字幕を付けます。
