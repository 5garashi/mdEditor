mdEditor is a free Markdown editor for Windows, developed by 5garashi.com Design Office.

This demo shows opening and editing Markdown, previewing diagrams and equations, opening the preview in a separate window, switching both windows to dark mode, using the Syntax reference, and saving a PDF.
Recorded using source build 1.0.5. The developer confirmed that version 1.0.5 was published on Microsoft Store on 2026-10-13. This recording was not made using the Store-installed build.
