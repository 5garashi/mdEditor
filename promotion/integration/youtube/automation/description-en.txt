mdEditor is a free Markdown editor for Windows, developed by 5garashi.com Design Office.

This demo shows opening a document, editing Markdown, previewing diagrams and equations, and saving a PDF.
Recorded using source build 1.0.5. The Microsoft Store build number has not been verified.
