# mdEditor 更新資料 / Update materials

資料版 / Kit: 1.4.0 · 2026-10-16

日英のSNS画像、紹介PDF、投稿原稿です。主な機能追加は1.0.8、最新ソースは1.0.10。画面は公式リポジトリ docs/images の1.0.8掲載素材を使用し、画面内容を加工していません。Storeの配信版番号は未確認です。

Bilingual social images, one-page PDFs and post copy. Main additions: 1.0.8; latest source: 1.0.10; official screenshots: 1.0.8.

- `posts-ja.md` / `posts-en.md`: 媒体別原稿と画像の代替テキスト。
- `update-*-landscape.png`: 1600×1200の投稿画像。
- `one-page-*.pdf`: A4の紹介PDF。URLはクリック可能。
- `PUBLICATION.md`: 公開結果。原稿の完成と公開を区別します。

機能の根拠: https://github.com/5garashi/mdEditor/blob/main/CHANGELOG.md

デザイン出典: [Design Office Identity 4.15.0](https://5garashi.github.io/5garashi-identity/)（第3・4・6・7・8・9・12・13条、2026-10-16確認）。本文・制作コードは既存資料に従いMIT。公式ロゴはCC BY-ND 4.0で、形と色を変更していません。アプリ画面はmdEditorの公式掲載素材です。

確認範囲: Pillowで画像寸法、PyMuPDFでPDFのページ数・文字抽出・リンクを確認。本文ink/paperの比はWCAG相対輝度式で測定しvalidation.jsonに記録。PNGは固定画像のため代替テキストを併記。PDFはタグ付きPDFではありません。読み上げ・OSコントラストテーマ・拡大時の実ブラウザー表示は未確認で、WCAG 2.2 AAの完全準拠を宣言しません。新しい操作画面・音声・外部ファイル取得機能はありません。
