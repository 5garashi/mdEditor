## 公開方法

promotion/とsamples/を同じ親ディレクトリに配置してください。既存5garashi.comへの配置時もこの相対構造を維持します。index.htmlとen.htmlをトップページからリンクしてください。認定完了後、両ページのv1.0.5認定中という案内を公開状況に合わせて更新します。Storeの価格は未確認なので無料とは表記していません。

GitHub Pagesを使う場合はリポジトリ全体を静的公開し、/promotion/を入口にできます。公開とドメイン設定は未実施です。

ロゴは既存の公式SVGを改変せず複製しています。各SVG内の著作権とCC BY-ND 4.0を維持します。
