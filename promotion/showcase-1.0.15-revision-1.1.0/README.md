# mdEditor promotion videos / プロモーション動画

Version: 1.1.0 — [Changelog](CHANGELOG.md)

2026-10-23 の mdEditor ソース（アプリ表示版 1.0.15）を日・英・簡体字中国語で実収録しました。Store 配布バイナリーの撮影ではありません。

対応する VTT と chapters に字幕と説明一覧を保存しています。制作スクリプトは作業フォルダーのビルド、サンプル、既存音源、appAutoTester を参照します。パッケージ単体で収録を実行する構成ではありません。

中国語版の Word 取り込み場面は、収録用サンプルの XML を修正して撮り直し、同じ長さで差し替えています。記録の postproduction_replacements に区間と確認内容を保存しています。

構成は、3D の回転・拡大と紹介、各言語の diagram-test サンプルの上から下への閲覧、主要機能の実演です。画像ドロップ、本文幅50％・中央揃えを含みます。日本語の文字コード紹介は省き、後半も各言語の文書を背景にしています。ネイティブファイルダイアログは区間ごとカットし、背景のデスクトップはクリーム色の専用面で覆いました。

BGM: Light Steps — 5garashi.com設計事務所 / 5garashi.com Design Office（作曲・音源生成: Codex）, CC BY 4.0。従来音源を抜粋・反復・終端フェード。冒頭のフェードインなし。音楽の再生停止・音量調整は動画プレイヤーで行えます。

サンプル内の映画: Big Buck Bunny © 2008 Blender Foundation, CC BY 3.0, https://bigbuckbunny.org/ 。地図は OpenStreetMap の提供表記を収録画面に表示します。本収録ではユーザー指定によりネット上の画像・動画・地図の読み込みを許可しています。

確認: 実収録中の3D回転、図・数式描画、PDF生成、目次、画像配置を検証。全出力のデコードと冒頭100msの音量を検査。画面抜粋・contact-sheet と validation.json を参照してください。物理的な2台目のモニター、異常終了による復元、全操作のアクセシビリティは未検証です。構文・描画の成功だけを表示品質や完全準拠の確認とはしていません。

原アプリは変更せず、収録コピーの設定・復元領域だけを専用名に変更しています。過去の動画は保持しています。媒体別の公開状態は [今回の公開記録](../multichannel/update-2026-10-23/PUBLICATION.md) を参照してください。
