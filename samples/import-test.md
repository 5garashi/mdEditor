# 読み込みと書き出しのテスト

mdEditor で開ける形式と、「名前を付けて保存」で選べる形式を確かめるためのファイルです。各ファイルを「開く」かドラッグ＆ドロップで開き、「期待する結果」と見比べてください。英語版は、名前に `.en` が付いたファイルです（[import-test.en.md](import-test.en.md)）。中国語の手順は [import-test.zh-CN.md](import-test.zh-CN.md) で、英語版のファイルを使います。

> 外部の画像を確かめる項目は、「設定」→「インターネット」が「確認する」（初期設定）のときの結果です。

| [html-test.html](html-test.html) | HTML | Markdown への変換、取り除かれるもの、画像 |
| [word-test.docx](word-test.docx) | Word | Markdown への変換、画像の取り出し |
| [word-headings-test.docx](word-headings-test.docx) | Word（見出しのスタイルなし） | 文字の大きさから見出しを推し量る |

## 2. 開く

### 2.1 text-test.txt

1. text-test.txt を開きます。
2. ファイル名が「text-test.txt」のまま、変換のお知らせは出ません。

期待する結果（プレビュー）:

- 「1 回だけの改行は…」の行は、前の行とつながって 1 段落になる。
- 「空白が 2 つあります」の行と「\ を置いても」の行のあとは改行される（日本語の書体では、プレビューの \ が ¥ に見えます）。
- 「# 見出しになる行」だけが見出しになり、「#見出しにならない行」「＃ 見出しにならない行」「・中黒の行」はふつうの文のまま。
- リスト・番号付きリスト・チェックボックス・太字・リンク・引用・表・コードの枠・数式・脚注が表示される。

最後に、1 文字書き足して「保存」を押します。保存先は聞かれず、text-test.txt に上書きされます（確かめたら元に戻してください）。

### 2.2 html-test.html

期待する結果:

- お知らせ欄に「HTML を Markdown に変換して開きました」と出る。ファイル名は「html-test.md」になる。
- 見出し・太字・斜体・リンク・リスト（入れ子を含む）・表・数式（`$E = mc^2$` と `$$…$$`）・引用・コードが Markdown になる。
- 赤い文字は、色のない文字になる。
- 「サンプル画像」（同じフォルダーの画像）は表示される。
- インターネット上の画像は「外部の画像（github.githubassets.com）。読み込んでいません」の枠になり、お知らせ欄に「画像を読み込む」が出る。押すと表示される。
- ボタンは文字だけが残り、iframe・object・embed・スクリプトの文は残らない。
- html-test.html 自体は書き換えられない（保存すると .md を聞かれる）。

### 2.3 word-test.docx

期待する結果:

- お知らせ欄に「Word の文書を Markdown に変換して開きました」と出る。ファイル名は「word-test.md」になる。
- 見出し（1〜3）・太字・斜体・リンク・リスト・番号付きリスト・表・画像が Markdown になる。
- 画像はプレビューに表示され、編集画面では `word-test_files/image1.png` を指している。
- 「名前を付けて保存」で Markdown として保存すると、保存先に「word-test_files」フォルダーができ、画像が入る。

### 2.12 画像を編集画面に入れる

1. 保存してある Markdown ファイル（新しく作って保存したものでよい）を開きます。
2. sample.png を編集画面にドラッグ＆ドロップします。
3. 画面の切り取り（Windows キー＋Shift＋S）をして、編集画面に Ctrl+V で貼り付けます。

期待する結果:

- ドロップした位置に `![sample](文書名_files/sample.png)` が入り、文書の横の「文書名_files」フォルダーに画像が写される。
- 貼り付けた位置に `![](文書名_files/image-日付-時刻.png)` が入る。
- 保存していない新しい文書では、先に保存先を聞かれる。
- 編集画面以外（ボタンの並びなど）にドロップした画像は、2.11 と同じように画像の文書として開く。

## 3. 名前を付けて保存

[diagram-test.md](diagram-test.md) か text-test.txt を開いて、「名前を付けて保存」のファイルの種類を順に選びます。保存先は、このフォルダー以外（デスクトップなど）にしてください。

| 種類 | 期待する結果 |
| --- | --- |
| Markdown | 文書そのものが .md で保存され、以後の「保存」はそのファイルに上書きする |
| テキスト（そのまま） | 中身が Markdown のまま .txt で保存される |
| テキスト（記号なし） | 見出しや太字の記号が消え、リストは「・」、表はタブ区切り、リンクは「文字（アドレス）」、図は「［図］」になる。編集中の文書のファイル名は変わらない |
| PDF | 整形したプレビューの PDF |
| HTML | 1 つで完結する HTML（開くと見た目が同じ） |
| PNG | プレビューの画像。長い文書は「名前-1.png」「名前-2.png」…に分かれる |
| Word | Word の標準のスタイルの .docx。図と数式は画像 |
| CSV | 文書の中の表のカンマ区切り。表が 2 つ以上なら「名前-1.csv」… に分かれる。Excel で開いて文字化けしない |
| TSV | 文書の中の表のタブ区切り |
| Jupyter Notebook | 言語付きのコードの枠がコードのセル、それ以外が Markdown のセルになる。実行結果は入らない |
| JSON | 文書の中の表を、見出しの行を項目の名前にしたオブジェクトの配列にする。値は文字のまま（「007」の 0 も残る） |

- 拡張子と違う種類を選んだとき（例: 名前を「a.md」にして種類を Word にする）は、選んだ種類の拡張子（a.docx）で保存される。
- 表のない文書で CSV を選ぶと「この文書には表がありません」と出る。
